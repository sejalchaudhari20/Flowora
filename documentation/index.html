Flowora AI SaaS Template

Thank you for purchasing the Flowora HTML Template! This comprehensive documentation will guide you through installation, customization, and deployment.

  • Template Name: Flowora AI SaaS HTML Template
  • Version: 1.0.0

Flowora is a modern, ultra-premium HTML5 template engineered specifically for AI startups, SaaS companies, and technology software platforms. It is built using the cutting-edge Tailwind CSS v4 CDN, allowing you to customize the entire theme directly in HTML without needing complex Node.js build steps or Webpack setups.

It features buttery-smooth Lenis scrolling, dynamic GSAP entrance animations, and a flawless Dark Mode system built natively into the codebase.

3. Requirements

Flowora is a static HTML template powered by CDNs. It does not require Node.js, NPM, Webpack, or any databases to run. To work with this template, you will need:

  • A modern code editor (we highly recommend Visual Studio Code).
  • A local web server to prevent CORS issues with local files. (The Live Server extension in VS Code is perfect).
  • A modern web browser (Chrome, Firefox, Edge, Safari).
  • Basic knowledge of HTML and CSS.
  • A standard web hosting provider (cPanel, FTP/SFTP, or static hosting like Vercel/Netlify).

Note: Flowora is a frontend static HTML template. It does not include a backend (like PHP/MySQL or Node.js) for processing dynamic user data or form submissions. The included `php/contact.php` is a basic mailer script requiring standard PHP hosting.

4. Installation & Setup

Step 1: Extract the package

Download the ZIP file from TemplateMonster. Extract the ZIP file to a folder on your computer. Inside, you will find the `Main_Files` directory which contains the actual template.

Step 2: Open in Code Editor

Open Visual Studio Code. Go to `File > Open Folder...` and select the extracted `Main_Files/templates` directory.

Step 3: Run the template locally

Because the template relies on JS features and CDNs, simply double-clicking `index.html` might cause CORS errors. Instead, use a local server:

  1. In VS Code, go to the Extensions tab (Ctrl+Shift+X).
  2. Search for and install Live Server (by Ritwick Dey).
  3. Right-click on `index.html` in your file explorer.
  4. Select "Open with Live Server".

Step 4: Upload to Hosting

When you are ready to publish, upload the contents of the `templates` folder to your live server.

  • cPanel: Open File Manager, navigate to `public_html`, and upload your files there.
  • FTP/SFTP: Use FileZilla or Cyberduck to connect to your server, and drag the contents of the `templates` folder into the `public_html` or `www` directory.

Ensure that `index.html` is in the root directory of your public folder.

8. Changing the Logo

By default, Flowora uses a text-based logo with an icon. To replace it with your own image logo:

  1. Prepare your logo in SVG or high-res PNG format (recommended height: 40px).
  2. Place your logo file in assets/images/logo/.
  3. Open index.html (and other pages) and locate the logo in the <header> section.
  4. Replace the HTML code with an `img` tag.
<!-- Replace this: -->
<a href="index.html" class="flex items-center gap-2.5 text-xl font-bold...">
  <span><span class="text-3xl text-indigo-600 dark:text-indigo-400">F</span>lowora</span>
</a>

<!-- With this: -->
<a href="index.html" class="flex items-center">
  <img src="assets/images/logo/your-logo.svg" alt="Your Company" class="h-8 w-auto">
</a>

9. Changing Brand Colors

Flowora uses Tailwind CSS v4. The primary brand color is established using Tailwind's default `indigo` color palette classes.

To change the brand color across the site (e.g., from Indigo to Emerald), you simply need to run a Find and Replace in your code editor:

Find: indigo-
Replace with: emerald- (or blue-, rose-, violet-, etc.)

Tailwind v4 handles all the CSS variable mapping instantly via the CDN. No CSS compilation is required!

10. Changing Typography

The template uses Inter for body text and Manrope for headings. These are configured via the `<style type="text/tailwindcss">` block in the `<head>` of each HTML file.

<!-- 1. Load the new font from Google Fonts -->
<link href="https://fonts.googleapis.com/css2?family=Outfit:wght@400;700&display=swap" rel="stylesheet">

<!-- 2. Update the Tailwind theme configuration -->
<style type="text/tailwindcss">
  @theme {
    /* Replace Manrope with Outfit */
    --font-heading: "Outfit", sans-serif;
  }
</style>

11. Changing Images

All images are located in the assets/images/ folder. To replace an image:

  1. Add your new image to the assets/images/ directory.
  2. Locate the `<img>` tag in the HTML file.
  3. Update the `src` attribute to point to your new image.
Tip: For optimal performance, always compress your images (using tools like TinyPNG) and use modern formats like `.webp` where possible.

12. Navigation and Menu

The header navigation is located inside the <header> tag near the top of the HTML files. It uses ID anchor links (like `#features`) to scroll down the homepage.

To add a new menu item:

<!-- Inside the <nav> tag -->
<a href="index.html#new-section" class="hover:text-indigo-600 dark:hover:text-white transition-colors">New Item</a>

14. Blog System

Flowora includes a static blog interface. The homepage features a Blog grid. Clicking "Read Article" takes you to `blog-detail.html`.

How it works (Demo Setup)

To demonstrate dynamic-like loading without a backend, the template uses a simple JavaScript file: assets/js/blog-data.js.

  • blog-data.js contains a JSON array of blog articles.
  • When you click a link like blog-detail.html?id=1, the script on `blog-detail.html` reads the ID from the URL.
  • It fetches the matching article from `blog-data.js` and injects the title, image, and HTML content into the page.

For Production: If you are integrating this into a CMS (like WordPress) or a framework (Next.js), you will remove `blog-data.js` and render the `blog-detail.html` structure directly from your database using your chosen server language.

15. Contact Section

The homepage contains a Contact form section (`index.html#contact`).

The form's action attribute points to php/contact.php. This is a very basic PHP mailer script provided as a starter.

Important: The contact form is frontend-only. It will only send actual emails if your hosting server supports PHP and the `mail()` function is configured correctly by your hosting provider. For robust production use, we recommend connecting the form to a service like Formspree or EmailJS.

16. JavaScript Features

All custom interactions are written in vanilla JavaScript in assets/js/main.js.

  • Theme Toggle: Saves user preference (Light/Dark) to `localStorage` and toggles the `.dark` class on the `` element.
  • Lenis Smooth Scroll: Initializes `@studio-freight/lenis` for buttery smooth scrolling.
  • GSAP ScrollTrigger: Locates classes like `.gsap-fade-up`, `.gsap-feature-left`, and `.gsap-typing-heading` to trigger high-performance entrance animations as you scroll down the page.
  • Pricing Toggle: Swaps out text content based on HTML data-attributes when the billing switch is clicked.

22. Troubleshooting

CSS changes are not showing

Ensure your internet connection is active, as Tailwind is loaded via CDN. If you modified `assets/css/main.css`, clear your browser cache (Ctrl+F5) to force a reload.

Animations aren't working locally

Browsers often block cross-origin requests (CORS) when opening HTML files directly via `file://`. Always use a local server (like VS Code Live Server) to view the template locally.

Images are not loading

Check the image path and filename. Ensure that your image paths are correct relative to the HTML file you are editing. Ensure case-sensitivity matches your OS.
